# 快速开始指南

## 第一步：安装插件

### 方法A：开发者模式安装（推荐）

1. **下载项目**
   ```bash
   git clone https://github.com/your-username/deepseek-monitor.git
   # 或者直接下载ZIP文件并解压
   ```

2. **打开Edge扩展管理页面**
   - 在地址栏输入 `edge://extensions/`
   - 或者点击右上角菜单 → 扩展 → 管理扩展

3. **开启开发者模式**
   - 在页面左下角找到"开发人员模式"开关
   - 点击开启

4. **加载插件**
   - 点击"加载解压缩的扩展"按钮
   - 选择 `deepseek-monitor` 文件夹
   - 点击"选择文件夹"

5. **完成安装**
   - 插件图标将出现在浏览器工具栏
   - 访问 `http://127.0.0.1:3000/` 测试插件

### 方法B：生成图标后安装

1. **生成图标**（可选）
   ```bash
   # 需要安装Node.js
   node generate-icons.js
   ```

2. **按照方法A的步骤安装**

## 第二步：配置插件

1. **点击插件图标**
   - 在浏览器工具栏找到DeepSeek Monitor图标
   - 点击打开设置页面

2. **配置设置**
   - **目标网址**：默认 `http://127.0.0.1:3000/`，可改为其他网址
   - **API Key**：输入你的DeepSeek API密钥（可选）
   - **刷新间隔**：设置自动刷新时间（默认60秒）
   - **启用监控**：开启或关闭监控功能

3. **保存设置**
   - 点击"保存设置"按钮
   - 设置将自动生效

## 第三步：获取API Key（可选）

如果需要显示余额功能，需要获取DeepSeek API Key：

1. 访问 [DeepSeek开放平台](https://platform.deepseek.com/)
2. 注册并登录账号
3. 进入"API密钥"页面
4. 点击"创建新密钥"
5. 复制生成的密钥
6. 粘贴到插件设置中的"API Key"字段

## 第四步：测试插件

1. **启动测试服务器**（可选）
   ```bash
   # 使用Python
   python server.py
   
   # 或者使用npm
   npm start
   ```

2. **访问测试页面**
   - 打开浏览器访问 `http://127.0.0.1:3000/`
   - 页面右上角应显示监控浮窗

3. **验证功能**
   - 检查状态指示器颜色是否正确
   - 查看当前时间显示
   - 如果配置了API Key，检查余额显示
   - 点击刷新按钮测试手动刷新

## 常见问题

### Q: 插件图标没有显示？
A: 
- 确认已开启"开发人员模式"
- 检查插件是否已启用（在扩展管理页面）
- 尝试刷新浏览器

### Q: 浮窗没有出现？
A:
- 确认访问的网址与设置中的"目标网址"一致
- 检查插件是否已启用
- 查看浏览器控制台是否有错误信息（F12）

### Q: 无法获取余额？
A:
- 检查API Key是否正确
- 确认API Key有效且有余额
- 检查网络连接
- 查看浏览器控制台的错误信息

### Q: 状态显示不正确？
A:
- 确认系统时间准确
- 检查系统时区是否为北京时间
- 尝试点击刷新按钮

### Q: 如何更新插件？
A:
- 如果使用git clone，运行 `git pull` 获取最新代码
- 在扩展管理页面点击刷新按钮（圆形箭头图标）
- 或者重新加载扩展

## 功能说明

### 峰谷时段

- **高峰时段**：周一至周五（不含中国法定节假日）9:00-12:00, 14:00-18:00
  - 价格：¥2.00 / 1M tokens
  - 状态指示：红色圆点
  
- **空闲时段**：其余所有时间，含周末与法定节假日全天；调休上班的周末同样按空闲计费
  - 价格：¥1.00 / 1M tokens（高峰的一半）
  - 状态指示：绿色圆点

- **警告时段**：高峰开始前10分钟
  - 状态指示：黄色圆点

### 状态指示器

- **红色**：当前处于高峰时段
- **黄色**：即将进入高峰时段（10分钟内）
- **绿色**：当前处于空闲时段

### 余额显示

- 显示DeepSeek API账户余额
- 需要配置有效的API Key
- 单位：人民币（¥）
