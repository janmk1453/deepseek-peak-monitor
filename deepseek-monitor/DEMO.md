# 使用演示

## 第一步：启动测试环境

### 启动测试服务器

```bash
# 进入项目目录
cd deepseek-monitor

# 启动测试服务器（带模拟API）
python test-server.py

# 或者使用npm
npm run test
```

服务器启动后，你会看到类似这样的输出：

```
============================================================
DeepSeek Monitor 测试服务器
============================================================
服务器地址: http://127.0.0.1:3000/
测试页面:   http://127.0.0.1:3000/test.html
模拟API:    http://127.0.0.1:3000/user/balance
============================================================
按 Ctrl+C 停止服务器
============================================================
```

## 第二步：安装插件

1. **打开Edge浏览器**

2. **进入扩展管理页面**
   - 在地址栏输入：`edge://extensions/`
   - 或者点击右上角菜单 → 扩展 → 管理扩展

3. **开启开发者模式**
   - 在页面左下角找到"开发人员模式"开关
   - 点击开启（开关变为蓝色）

4. **加载插件**
   - 点击"加载解压缩的扩展"按钮
   - 选择 `deepseek-monitor` 文件夹
   - 点击"选择文件夹"

5. **确认安装成功**
   - 插件图标出现在浏览器工具栏
   - 在扩展列表中看到"DeepSeek Monitor"

## 第三步：测试插件

### 访问测试页面

1. **打开新标签页**

2. **访问测试页面**
   - 地址栏输入：`http://127.0.0.1:3000/test.html`
   - 或者：`http://127.0.0.1:3000/`

3. **观察插件效果**
   - 页面右上角出现监控浮窗
   - 显示当前状态（红/黄/绿色圆点）
   - 显示当前时间
   - 显示余额（如果配置了API Key）

### 测试各项功能

#### 1. 状态指示器
- 查看圆点颜色
- 根据当前时间判断是否正确：
  - 周一至周五（不含中国法定节假日）9:00-12:00, 14:00-18:00 → 红色；周末与法定节假日全天为绿色
  - 其他时间 → 绿色
  - 高峰开始前10分钟 → 黄色

#### 2. 拖动功能
- 按住浮窗标题栏
- 拖动到任意位置
- 释放鼠标

#### 3. 关闭浮窗
- 点击右上角的 × 按钮
- 浮窗隐藏

#### 4. 刷新数据
- 点击底部的刷新按钮
- 数据立即更新

#### 5. 配置设置
- 点击浏览器工具栏的插件图标
- 修改设置
- 点击"保存设置"

## 第四步：配置API Key（可选）

### 获取DeepSeek API Key

1. 访问 [DeepSeek开放平台](https://platform.deepseek.com/)
2. 注册并登录
3. 进入"API密钥"页面
4. 创建新密钥
5. 复制密钥

### 配置到插件

1. 点击插件图标
2. 在"API Key"字段粘贴密钥
3. 点击"保存设置"
4. 点击"立即刷新"

## 第五步：实际使用

### 在DeepSeek网站使用

1. **配置目标网址**
   - 打开插件设置
   - 将"目标网址"改为：`https://chat.deepseek.com/`
   - 保存设置

2. **访问DeepSeek网站**
   - 打开 `https://chat.deepseek.com/`
   - 插件浮窗自动显示

3. **监控使用情况**
   - 随时查看峰谷状态
   - 了解当前价格
   - 监控余额变化

## 故障排除演示

### 问题1：浮窗不显示

**检查步骤**：
1. 确认访问的网址与设置一致
2. 检查插件是否启用
3. 查看浏览器控制台错误

**解决方法**：
```javascript
// 在控制台运行
chrome.storage.local.get('settings', console.log)
```

### 问题2：余额显示错误

**检查步骤**：
1. 确认API Key正确
2. 检查网络连接
3. 查看控制台错误

**解决方法**：
```javascript
// 测试API连接
fetch('https://api.deepseek.com/user/balance', {
  headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
}).then(r => r.json()).then(console.log)
```

### 问题3：状态不准确

**检查步骤**：
1. 确认系统时间正确
2. 检查系统时区是否为北京时间

**解决方法**：
- Windows：设置 → 时间和语言 → 日期和时间
- 确保"自动设置时区"开启
- 时区选择：(UTC+08:00) 北京，重庆，香港特别行政区，乌鲁木齐
