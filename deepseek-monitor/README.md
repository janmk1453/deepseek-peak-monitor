# DeepSeek Monitor - Edge浏览器插件

一个用于监控DeepSeek API峰谷时间和余额的Edge浏览器插件。

## 功能特性

- **实时峰谷状态监控**：自动检测当前是高峰还是空闲时段
  - 高峰：周一至周五（不含中国法定节假日）9:00-12:00、14:00-18:00
  - 空闲：其余时段，含周末、法定节假日全天，以及调休上班的周末
  - 内置国务院公布的放假安排（2023-2026 年），未收录年份可手动补充空闲日期
- **可视化状态指示**：
  - 🔴 红色：高峰时段（法定节假日除外）
  - 🟡 黄色：高峰开始前10分钟
  - 🟢 绿色：空闲时段（含周末与法定节假日）
- **余额显示**：实时显示DeepSeek API账户余额
- **价格对比**：清晰展示峰谷价格差异
- **可自定义设置**：支持配置目标网址、API Key、刷新间隔等
- **现代美观UI**：简洁的设计，支持深色模式

## 安装步骤

### 方法1：开发者模式安装（推荐）

1. 下载或克隆本项目
2. 打开Edge浏览器，进入 `edge://extensions/`
3. 开启右上角的"开发人员模式"
4. 点击"加载解压缩的扩展"
5. 选择 `deepseek-monitor` 文件夹
6. 插件安装完成！

### 方法2：生成图标后安装

1. 安装Node.js（如果没有的话）
2. 在项目目录运行：
   ```bash
   node generate-icons.js
   ```
3. 按照方法1的步骤安装插件

## 使用方法

1. 安装插件后，访问 `http://127.0.0.1:3000/`
2. 页面右上角会显示监控浮窗
3. 点击插件图标可以打开设置页面

### 基本操作

- **拖动浮窗**：按住标题栏拖动
- **关闭浮窗**：点击右上角的 × 按钮
- **刷新数据**：点击底部的刷新按钮

### 配置设置

点击插件图标打开设置页面：

1. **目标网址**：设置要监控的网站地址（默认：http://127.0.0.1:3000/）
2. **API Key**：输入你的DeepSeek API密钥（用于获取余额）
3. **刷新间隔**：设置自动刷新的时间间隔（10-3600秒）
4. **启用监控**：开启或关闭监控功能

## 获取DeepSeek API Key

1. 访问 [DeepSeek开放平台](https://platform.deepseek.com/)
2. 注册并登录账号
3. 在"API密钥"页面创建新的密钥
4. 复制密钥并粘贴到插件设置中

## 技术实现

- **Manifest V3**：使用最新的Chrome扩展API
- **Service Worker**：后台定时检查峰谷时间
- **Content Script**：在页面中注入监控界面
- **Chrome Storage**：存储设置和监控数据
- **Chrome Alarms**：实现定时刷新功能

## 注意事项

1. **API Key安全**：API Key存储在浏览器本地，不会上传到任何服务器
2. **余额获取**：需要有效的API Key才能获取余额信息
3. **时间计算**：按系统本地时间判断峰谷（默认即北京时间）；节假日规则以国务院公布的放假安排为准，内置 2023-2026 年数据
4. **网络要求**：需要网络连接才能获取余额数据

## 故障排除

### 插件无法加载

- 确认已开启"开发人员模式"
- 检查插件文件是否完整
- 查看浏览器控制台是否有错误信息

### 无法获取余额

- 检查API Key是否正确
- 确认API Key有余额
- 检查网络连接

### 状态显示不正确

- 确认系统时间是否准确
- 检查时区设置（应为北京时间）
- 若当前年份不在 2023-2026 范围内，可在设置页“额外空闲日期”中补充当年放假日期
