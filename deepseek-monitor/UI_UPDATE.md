# UI 更新说明

## 更新内容

根据你的要求，我对插件UI进行了以下修改：

### 1. 窗口大小
- **之前**: 220px 宽度
- **现在**: 180px 宽度（更紧凑）

### 2. 状态指示器
- **之前**: 使用彩色圆点
- **现在**: 使用半透明背景颜色
  - 🔴 红色背景：高峰时段
  - 🟡 黄色背景：高峰开始前10分钟
  - 🟢 绿色背景：空闲时段

### 3. 保留的功能
- ✅ 余额显示
- ✅ 刷新按钮
- ✅ 关闭按钮

### 4. 新增功能
- ✅ 倒计时显示
  - 高峰时段：显示"高峰结束 HH:MM:SS"
  - 空闲时段：显示"高峰开始 HH:MM:SS"
  - 每秒自动更新

## 功能说明

### 倒计时逻辑
- **高峰时段**: 显示距离当前高峰结束的时间
- **空闲时段**: 显示距离下次高峰开始的时间
- **警告时段**: 显示距离高峰开始的时间
- **周末**: 显示距离下周一高峰开始的时间

### 自动刷新
- 每秒更新倒计时
- 按照设置的间隔自动刷新数据
- 手动点击刷新按钮立即更新
